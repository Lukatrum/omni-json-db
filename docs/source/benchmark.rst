Benchmarking
============

Testing
-------


.. code-block:: python

   >>> from omni_json_db import JDb
   >>> size = 1_000_000
   >>> jdb = JDb(data_type='J+J')
   >>> data = {f'key{k}':k for k in range(size)}
   
   >>> # Benchmarking operations
   >>> jdb += data        # insert
   >>> jdb[:]             # get_all
   >>> jdb -= data        # remove
   >>> jdb ^= data        # revert=unremove
   >>> jdb[data] = -1     # replace
   >>> jdb ^= data        # revert=unmodify
   >>> print(jdb == data) # Output: True
